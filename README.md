# FounderOS

Sıfırdan tek kişilik yapay zeka servis işini doksan günde kuran sistem.

Bu depo FounderOS eklentisinin kurulum kaynağıdır. Eklentiyi buradan kurarsın,
ama sistemin çalışması için FounderOS aboneliğine bağlı bir CRM hesabı ve
lisans anahtarı gerekir; ikisi de satın alma sonrası e-postayla gelir.

## Kurulum

Adım adım anlatım: https://founderos.so/kurulum

Kısaca: Claude uygulamasında yazı kutusunun yanındaki artı düğmesi, Plugins,
Browse plugins, sağ üstteki artı, Add from a repository, sonra bu adres:

    founderconsultingco/eklenti
